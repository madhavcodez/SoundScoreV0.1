# Phase 1B Ownership Map

## Backend

- Auth + sessions + rate limiting: backend-platform
- Ratings/reviews/lists/social: backend-core
- Recaps + notifications: backend-growth
- DB migrations + Redis caching + CI infra: backend-platform

## Android

- Repository + sync/outbox + API integration: mobile-data
- Navigation/deep-link/share entry behavior: mobile-navigation
- Profile/push preference/recap UX: mobile-product

## Contracts and Docs

- API/event schemas in `packages/contracts`: contracts-owner
- Runbooks, closure checklists, milestone traceability: release-ops
